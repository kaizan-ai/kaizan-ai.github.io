# Cloudflare redirects

kaizan.ai is served by GitHub Pages behind Cloudflare. GitHub Pages cannot send HTTP
redirects, so retired URLs are meta-refresh stub pages (see `tools/redirects.json`).
Cloudflare can send real `301`s, which are cleaner for SEO and faster for visitors.

Two things to set up in the Cloudflare dashboard. Both are optional and safe to add at
any time: the stub pages stay in the repo as a fallback.

## 1. Bulk redirects (every URL in `tools/redirects.json`)

`bulk-redirects.csv` is regenerated by `python3 tools/build.py`; do not edit it by hand.
It has one row per redirect, for the UK URL and its `/us/` twin, with and without the
trailing slash. It also redirects `/index.html` and `/us/index.html` to the clean URL.

1. Cloudflare dashboard, kaizan.ai account: **Bulk Redirects** (Account home → Bulk
   Redirects, or Rules → Redirect Rules → Bulk Redirects).
2. **Create Bulk Redirect List**, choose *Upload CSV*, and upload `bulk-redirects.csv`.
   The file has no header row. Columns: `source_url, target_url, status_code,
   preserve_query_string, include_subdomains, subpath_matching, preserve_path_suffix`.
3. **Create Bulk Redirect Rule**, pick that list, and enable it.
4. After each change to `tools/redirects.json`, re-upload the CSV to the same list.

## 2. `/<page>/index.html` duplicates (one wildcard rule)

Every page is also reachable at `<path>/index.html`. Pages already carry a canonical tag
and a small script that redirects, but a server-side rule removes the duplicate fully:

Rules → **Redirect Rules** → Create rule (*Wildcard pattern* template)

- **If the request URL matches:** `https://kaizan.ai/*/index.html`
- **Then redirect to:** `https://kaizan.ai/${1}/`
- **Status code:** 301, preserve query string on.

(`/index.html` itself is in the CSV.)
