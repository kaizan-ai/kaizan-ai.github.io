**Customer retention software, 60-second decision table: start with the problem**

| Use it when | The type you need | Tools named |
|---|---|---|
| You run a large self-serve or usage-metered customer base and need to score in-product behaviour | 1. Enterprise CS and retention platform | Gainsight, ChurnZero, Totango, Planhat |
| You lose clients with no warning, and your RAG spreadsheet is out of date by the time anyone reads it | 2. Conversation-based client intelligence | Kaizan |
| You want a read on how happy clients are, twice a year, nothing more | 3. Survey or NPS tool | Delighted |
| You want one more field on the CRM you already run, not another system | 4. CRM health-score add-on | HubSpot, Salesforce |

Name the problem first. Then compare the tools of that type.
