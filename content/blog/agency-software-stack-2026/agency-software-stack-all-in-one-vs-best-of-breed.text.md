**What you actually give up with each choice: All-in-one or best-of-breed?**

| | Option A: All-in-one | Option B: Best-of-breed |
|---|---|---|
| Examples | Scoro, Productive, Function Point, Workamajig | The strongest tool for each job, connected together |
| Wins on | One login, one system of record, one vendor, no integration maintenance | Depth in every job |
| Gives up | Depth: the CRM and reporting are rarely best in class | Integration debt, and more logins to adopt |

**Agency size: what usually works**
- **Around 20 people:** Best-of-breed, kept deliberately lean
- **Around 80 people:** All-in-one starts paying off
- **Around 200 people:** A hybrid: an all-in-one core plus specialist layers

All-in-one trades best-in-class for good-enough-everywhere. Best-of-breed trades fewer logins for depth.
